# 🏠 FindMyHome - Telegram Bot с AI и Google Docs

Интеллектуальный Telegram-бот, который использует Google Docs как живую базу знаний для поиска вещей в вашей квартире. Бот работает через OpenRouter API и поддерживает различные AI модели.

## 🌟 Возможности

- 📱 **Telegram бот** - удобный интерфейс для общения
- 📄 **Google Docs интеграция** - документ как база знаний
- 🤖 **AI через OpenRouter** - мощные языковые модели (Claude, GPT-4, и др.)
- 🔍 **Умный поиск** - векторный поиск релевантных частей документа
- 💰 **Оптимизация токенов** - chunking и кэширование для экономии
- 🔄 **Автообновление** - актуальные данные при каждом запросе
- 🇷🇺 **Русский язык** - полная поддержка русского языка

## 📋 Как это работает

1. Вы создаёте Google Документ с описанием того, где что находится в квартире
2. Бот получает доступ к документу через Google Docs API
3. При каждом вопросе бот:
   - Загружает актуальную версию документа
   - Разбивает на фрагменты (chunks)
   - Находит наиболее релевантные части
   - Отправляет их вместе с вопросом в AI
   - Возвращает ответ в Telegram

## 🚀 Быстрый старт

### Предварительные требования

- Node.js 18+ и npm
- Telegram аккаунт
- Google аккаунт
- OpenRouter аккаунт (или ключ от OpenAI/Anthropic)

### 1. Установка зависимостей

```bash
npm install
```

### 2. Создание Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям (название и username бота)
4. Скопируйте полученный токен

### 3. Настройка OpenRouter

1. Зарегистрируйтесь на https://openrouter.ai/
2. Пополните баланс (можно начать с $5)
3. Создайте API ключ в разделе "Keys"
4. Скопируйте ключ

### 4. Настройка Google Docs

Следуйте подробной инструкции в [GOOGLE_SETUP.md](./GOOGLE_SETUP.md)

Краткая версия:
1. Создайте проект в Google Cloud Console
2. Включите Google Docs API
3. Создайте Service Account
4. Скачайте JSON credentials → сохраните как `google-credentials.json`
5. Предоставьте Service Account доступ к вашему документу

### 5. Конфигурация

Создайте файл `.env`:

```bash
cp .env.example .env
```

Заполните переменные:

```env
# Telegram Bot Token из BotFather
TELEGRAM_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

# OpenRouter API Key
OPENROUTER_API_KEY=sk-or-v1-...

# Модель для OpenRouter (опционально, по умолчанию Claude 3.5 Sonnet)
OPENROUTER_MODEL=anthropic/claude-3.5-sonnet

# ID вашего Google документа (из URL)
GOOGLE_DOC_ID=1abc123def456ghi789jkl

# Путь к credentials (если не в корне проекта)
GOOGLE_SERVICE_ACCOUNT_PATH=./google-credentials.json

# Настройки обработки текста (опционально)
MAX_CONTEXT_TOKENS=8000
CHUNK_SIZE=1000
CHUNK_OVERLAP=200
```

### 6. Запуск

**Разработка (с hot reload):**
```bash
npm run dev
```

**Production:**
```bash
npm run build
npm start
```

## 🔧 Настройки

### Модели OpenRouter

Вы можете использовать любую модель из [списка OpenRouter](https://openrouter.ai/models):

```env
# Anthropic Claude
OPENROUTER_MODEL=anthropic/claude-3.5-sonnet
OPENROUTER_MODEL=anthropic/claude-3-opus

# OpenAI
OPENROUTER_MODEL=openai/gpt-4-turbo
OPENROUTER_MODEL=openai/gpt-3.5-turbo

# Google
OPENROUTER_MODEL=google/gemini-pro

# Meta
OPENROUTER_MODEL=meta-llama/llama-3-70b-instruct
```

### Оптимизация токенов

Настройте параметры для баланса между качеством и стоимостью:

```env
# Максимум токенов для контекста (меньше = дешевле, но может потерять информацию)
MAX_CONTEXT_TOKENS=8000

# Размер одного фрагмента (больше = меньше фрагментов, но точнее поиск)
CHUNK_SIZE=1000

# Перекрытие между фрагментами (больше = лучше контекст, но больше дублей)
CHUNK_OVERLAP=200
```

## 🐛 Решение проблем

### Бот не отвечает

1. Проверьте, что токен Telegram корректный
2. Убедитесь, что бот запущен (`npm run dev`)
3. Проверьте логи в консоли

### Ошибка доступа к Google Docs

```
Error: The caller does not have permission
```

**Решение**: Предоставьте Service Account доступ к документу ([GOOGLE_SETUP.md](./GOOGLE_SETUP.md#6-предоставление-доступа-к-google-документу))

### Ошибка OpenRouter API

```
OpenRouter API error: Insufficient credits
```

**Решение**: Пополните баланс на https://openrouter.ai/credits

### Бот даёт неточные ответы

1. Попробуйте команду `/refresh` для обновления документа
2. Увеличьте `MAX_CONTEXT_TOKENS` в `.env`
3. Используйте более мощную модель (например, `anthropic/claude-3-opus`)
4. Улучшите структуру документа (добавьте заголовки, более точные описания)

## 💰 Стоимость

OpenRouter тарифицируется по токенам. Примерные цены для популярных моделей:

| Модель | Input (за 1M токенов) | Output (за 1M токенов) |
|--------|----------------------|------------------------|
| Claude 3.5 Sonnet | $3 | $15 |
| GPT-4 Turbo | $10 | $30 |
| GPT-3.5 Turbo | $0.50 | $1.50 |

Пример: для документа на 5000 слов (~6000 токенов) и вопроса на 20 слов (~25 токенов), один запрос с Claude 3.5 Sonnet будет стоить ~$0.02
